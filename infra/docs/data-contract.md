# Phase 1 data contract (schema 1)

All CLI commands run from the repository root. The authoritative phase specification is `Phase_Docs/PHASE 1.md`.

Class IDs are stable: **0 Normal, 1 Pneumonia, 2 COVID-19**. NIH positive Pneumonia/Infiltration/Consolidation are weak pneumonia proxies, including rows with additional findings. NIH exact No Finding maps to Normal. CheXpert positive Pneumonia or Consolidation maps to Pneumonia; each uncertain target is ignored, a different certain positive target can still establish Pneumonia. Normal requires certain No Finding with no other certain positive and no uncertain pneumonia target. Remaining and lateral CheXpert images are excluded from primary indices. Original findings and exclusion reasons remain in the full manifest.

`research/data/raw/{nih,covidqu}/` holds a version-pinned original ZIP, original metadata, extracted files and an acquisition receipt. Archive members are CRC-checked while extracting. SHA-256 is a local reproducibility checksum, not a publisher-provided signature. Inventory validation and full image decoding happen before a processed manifest is issued. COVID inputs use only `Lung Segmentation Data/**/images/`, never masks or the overlapping infection subset. CheXpert is optional at `research/data/raw/chexpert/` with its small release and `train.csv`; enable it in the YAML after authorized acquisition.

`research/data/processed/manifest.csv` preserves all source records. `image_id` is a source prefix and a stable hash of the raw relative path; it does not depend on an absolute drive location. Columns include dataset, raw_relative, patient_id (namespaced, blank where unavailable), original_labels (JSON), label (-1 for excluded), exclusion_reason, official_split, processed_path, native and processed pixel hashes, dimensions. `processed_path` is relative to the processed root. Grayscale PNGs are lossless at 224 x 224. The loader replicates grayscale into RGB, converts uint8 to [0,1], then applies ImageNet mean `[0.485,0.456,0.406]` and std `[0.229,0.224,0.225]` exactly once.

`primary_manifest.csv` selects the primary task, excludes conflicting labels on identical processed pixels, deduplicates pixels and adds group_id and split. Patient identifiers and exact pixel duplicates form connected groups before splitting. NIH/CheXpert groups are stratified by source and dominant label at 70/15/15 where group counts permit. Ratios refer to patient groups, so image counts can differ. COVID official splits are preserved; their realized ratios are recorded. The most conservative test > val > train assignment wins if a duplicate group touches multiple official splits. COVID lacks patient identifiers; official splits plus exact duplicate grouping do not prove there are no unknown shared patients or near-duplicates.

Every index CSV has exactly one column, `image_id`. Central indices are `processed/splits/{train,val,test}.csv`; clinic indices are `partitions/client_00/{train,val}.csv` through `client_09`. Test is centralized and never assigned to clients. All train and validation images appear exactly once in clinic indices; patient/duplicate groups stay within one clinic. `partition.json` contains the config hash, actual source list, sizes, parameters and audit results. `summary.csv`, `report.md`, `distribution.png`, `assignments.csv` and `tracking.json` provide statistics and provenance. Regenerate partitions after adding CheXpert; adding a source changes the experiment/data configuration and invalidates prior baseline comparability.

`research.src.data_prep.dataset.ImagingDataset(processed_root, index_file)` is the Phase 2 interface and returns `(float32 CPU tensor [3,224,224], integer class_id)`. It resolves stable IDs through the primary manifest. No FL or training implementation is included in Phase 1.
